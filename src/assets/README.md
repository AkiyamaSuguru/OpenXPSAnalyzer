# Assets

Place packaging icons, splash artwork, and optional fonts in this directory.

- Icons and splash artwork that the author made for this project are reserved design. They are not covered by the AGPL; see the license section (许可说明) of the [README](../../README.md#许可说明).
- Add fonts or artwork made by others only if their licenses allow redistribution, for example fonts under the SIL Open Font License (OFL), and ship each one with its license file.
- Never add system fonts such as Times New Roman, SimSun or Microsoft YaHei. They come with the operating system under licenses that do not allow redistribution, and the plots already use the fonts installed on each system.
